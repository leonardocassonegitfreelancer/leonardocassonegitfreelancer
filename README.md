# Leonardo Cassone

**Digital marketing, with the data layer built properly.**

I work where marketing decisions meet data: collecting analytics and lead data
reliably, joining it across sources, and making it safe for a team (or an AI

build the plumbing I wish every marketing team had.

## What I build

- **[zero-cost-marketing-data-hub](https://github.com/leonardocassonegitfreelancer/zero-cost-marketing-data-hub)**
  GA4, Search Console and lead outcomes in one free-tier D1 database, joined
  by page. The quiet mistakes that make a joined dashboard wrong while it
  still looks right, documented and tested.
- **[readonly-d1-mcp](https://github.com/leonardocassonegitfreelancer/readonly-d1-mcp)**
  A read-only MCP server for Cloudflare D1: a read-scoped credential as the
  real guarantee, per-person tokens, first-use human approval and a data
  dictionary the model reads before it writes SQL.
